# AI Conference Registration Automation

## Overview
This project automates the conference registration process using Make.
When a user submits the Google Form, the workflow:
1. Detects the new registration in Google Sheets.
2. Uses AI to generate a personalized confirmation email.
3. Sends the email automatically using Gmail.

## Workflow
Google Form
↓
Google Sheets
↓
AI by Make
↓
Gmail

## Technologies Used
- Make
- Google Forms
- Google Sheets
- Gmail
- AI by Make

## Features
- Automatic registration processing
- AI-generated personalized confirmation emails
- No manual intervention required
